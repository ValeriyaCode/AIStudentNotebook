# Зображення нового дизайну

Розмістіть у цій папці окремі готові зображення (PNG або WebP):

- `teacher-login.png` — персонаж для сторінки входу, з роботом і книжками, якщо це одна композиція;
- `teacher-dashboard.png` — персонаж для змісту зошита;
- `robot.png` — окремий робот;
- `books.png` — книжки;
- `leaves.png` — декоративне листя;
- `logo.svg` або `logo.png` — логотип;
- `background.webp` — фон без тексту та елементів інтерфейсу, якщо він є окремо.

Для персонажів і декору бажаний прозорий фон. Надсилайте оригінали без зменшення якості. Назви можуть відрізнятися — головне, щоб було зрозуміло, що зображено.

Повні макети з кнопками та написами слугують візуальним прикладом. Поля входу, заголовки, прогрес і картки розділів створюються у HTML/CSS.
